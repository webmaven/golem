== 0.1.0a3 - 2026-09-01

=== Added

* *ASG-Level API Doc Macro Splicing (Issue #10):*
** New `on_asg_created` plugin hook implementation in `golem.plugins.apidoc` that splices `golem:apidoc[pass:[...]]` block macros directly into the document Abstract Semantic Graph after full semantic resolution.
** New `AsciiDocApi.get_asg_nodes(symbol, depth, heading_level_offset)` method in `golem.plugins.apidoc.core` that renders a Python symbol to AsciiDoc markup and returns structured ASG block dictionaries ready for tree splicing.
** `heading_level_offset` macro parameter: allows embedded API documentation headings to be adjusted relative to the surrounding document section depth.
** Unresolvable macro targets now produce a visible `[WARNING]` admonition block in rendered output instead of silently disappearing.
** Escaped macros (`\golem:apidoc[pass:[...]]`) are correctly unescaped to literal text without triggering expansion.
* *AsciiDoc Multi-View Derived Rendering Engine:*
** Interactive tabbed code containers generated at build time via `render`, `views`, `display`, or `formats` attributes on `[source,asciidoc]` blocks.
** Supports four canonical compilation channels: `source` (raw AsciiDoc), `asg` (parsed ASG JSON), `html` (rendered HTML5 markup), and `preview` (live rendered component).
** Zero-JS tab switching using modern declarative CSS `:has()` and `input[type=radio]` controls with physical folder tab styling.
** Deterministic unique listing identifiers (`get_listing_uid`) for stable anchor targeting and navigation.
* *Enhanced Code Listing Headers & Actions:*
** Semantic `<header class="listing-header">` featuring listing titles, uppercase language badges (`.badge-lang`), role badges (`.badge-test`, `.badge-shared`, `.badge-reset`), and a one-click clipboard copy button (`.listing-copy-btn`).
** Context-aware clipboard copying that dynamically copies the active tab pane.
* *UI Macro Styling (`:experimental:`):*
** Dedicated 3D keycap styling for `<kbd>` with border bevel and surface background.
** Dedicated action button styling for `<b class="button">` / `.button` with sans-serif UI font and 5px rounded corners.
** Dedicated sans-serif menu hierarchy styling for `<span class="menuseq">` and menu path components.
* *CLI Build & Serve Enhancements:* Added `-q`/`--quiet` flag and elapsed execution timing to `golem build`, along with startup compilation status and live rebuild progress in `golem serve`.
* *Server-Side Syntax Highlighting:* Pygments-powered syntax highlighting integrated into the build pipeline with Fired Clay styling.
* *Project Hygiene & CI Checks:* Added `CONTRIBUTING.adoc` contributor guide and AST-based CI canary test (`tests/test_syntax_invariants.py`).
* *Test Coverage Configuration:* Added `pytest-cov` and `coverage[toml]` to dev dependencies with configured targets in `pyproject.toml`.

=== Changed

* *`on_pre_parse` Macro Expansion Deprecated:* The `on_pre_parse` hook in `golem.plugins.apidoc` is now a deprecated fallback for `golem:apidoc[...]` macro expansion. It emits a `logger.warning` when invoked and will be removed in a future release. The `on_asg_created` hook is the preferred expansion path.
* *Table Column Alignment Propagation:* `golem.renderer` now propagates column-level `halign`/`valign` specifications from `cols=` declarations (e.g. `cols="<,^,>"`) down to individual cell nodes in the ASG. Cell-level alignment always takes precedence over column-spec defaults.
* *Dot-Ordered List Normalization:* `golem.renderer` now detects and repairs a parser quirk in `asciidoctrine` ≥ 0.2.0a5 where the first item of a dot-ordered list (`. First item`) is promoted to the list's `title` attribute. Affected lists are normalized in-place before rendering; consecutive fractured list blocks are merged.
* *Default Theme Table Styling:* The `default/skeleton.pt` template now ships full AsciiDoc table semantics: `halign-left/center/right/justify`, `valign-top/middle/bottom`, `stripes-even/odd/hover`, `frame-all/sides/topbot/none`, and `grid-all/cols/rows/none` CSS classes; styled `caption.title`; and `colgroup col` proportional-width support.
* *Default Theme Palette & Radii Refinements:*
** Lightened default light mode background to clean warm paper (`#faf9f5`).
** Refined inline code corner radius to `2px` for crisper inline badges, and increased action button corner radius to `5px` to clearly differentiate clickable UI controls.
** Styled dev server diagnostic error overlay with dark theme and aligned source code error carets.
* *Plugin Execution Gating:* Refactored `get_plugin_manager()` to a two-pass discovery-registration architecture where `config.plugins` is the sole authority for activation and execution order.
* *Dependency Upgrades:* Updated `asciidoctest` import surface to 0.2.0a4 top-level exports (`AsciiDocTestFailure`, `extract_and_run_docstring_tests` now importable from `asciidoctest` directly). Bumped `asciidoctrine` to `>=0.2.0a5`, `asciidoctype` to `>=0.1.0a4`, and added `pygments>=2.18`.
* *AsciiDoc Docstrings:* Standardized docstrings across all internal modules to AsciiDoc format using `asciidocstring` conventions.
* *CSS Visual Hierarchy:* Enhanced default theme typography, admonition pill labels, code listing language badges, table breakouts, and per-page layout classes.

=== Fixed

* *Syntax Highlighting Callout Preservation:* Overrode `GolemRenderer.highlight_code()` to preserve AsciiDoc `<i class="conum">` callouts through Pygments and re-inject badges into highlighted lines; removed duplicate CSS counter badges on `ol.colist > li`.
* *ApiDoc Plugin Macro Protection:* Protected delimited verbatim blocks, inline code backticks, and backslash-escaped macros (`\golem:apidoc[...]`) from unintended macro expansion in both `on_asg_created` and `on_pre_parse` paths.
* *Listing Focus Outline Scoping:* Limited `.listingblock` focus outline highlight strictly to code content and pane interactions via `:has(.listing-content:focus-within, .listing-panes:focus-within)`.
* *Snippet Compilation Hardening:* Hardened isolated multi-view snippet compilation against infinite recursion, attribute injection, and template leakages, with sanitized listing role identifiers.
* *Python Exception Handling:* Corrected five occurrences of deprecated Python 2 `except A, B:` syntax to Python 3 `except (A, B):`.
* *Plugin Hook Robustness:* Isolated plugin exceptions across all build hooks and added conflict warnings when multiple plugins modify the same value.
* *Cross-Platform File Locking:* Replaced POSIX-only `fcntl` cache locking with cross-platform `filelock`.
* *Configuration Normalization:* Deduplicated TOML parsing across `golem.toml` and `pyproject.toml` into a centralized normalizer helper.
* *Navigation & TOC Performance:* Cached `discover_navigation()` tree during build cycles and eliminated duplicated text in TOC anchor generation.
* *CLI Scaffolding and Package Info:*
** Dynamically resolved `--version` from package metadata and author name from `git config` in `golem init`.
* *Repository Cleanliness:* Removed internal review artifacts from tracking and added pattern ignores to `.gitignore`.
* *Dev Server Disconnects:* Downgraded client socket disconnect exceptions to debug-level logging.
* *Pygments HTML-Escaped Quotes in Derived Views:* Assertions in derived-view rendering now accept both raw (`"`) and HTML-escaped (`&quot;`) forms of JSON output, fixing failures when Pygments is active.

== 0.1.0a2 - 2026-08-24

=== Added

* *Fine-Grained Cache Invalidation (Issue #1):*
** AST/ASG `node_types` inventory recorded per page in `.golem/cache.json`.
** Theme template fingerprinting and scoped cache invalidation for specific node template changes (e.g. `listing.html` only recompiles pages with code blocks).
** New Pluggy lifecycle hook `golem_mark_stale(changed_files, cache_metadata)` enabling plugins to perform selective cache invalidation.
* *Automated API Documentation Generation (`golem apidoc`):*
** Built-in plugin `golem.plugins.apidoc` using Griffe and `asciidocstring` to introspect packages and generate clean AsciiDoc API reference documentation.

=== Changed

* *Upgraded Dependencies:*
** Upgraded `asciidoctrine` dependency requirement to `>=0.2.0a3` (incorporating parser memoization, underscore emphasis fixes, and listing block bracket fixes).
** Upgraded `asciidoctest` dependency requirement to `>=0.2.0a3` (supporting AST section scoping and named test contexts).

=== Fixed

* *API Reference Formatting:*
** Description list multi-line formatting in apidoc output avoiding parser bloat.
** Truncation of large inline attribute constants (such as HTML templates).
** Heading level offset adjustment for docstrings opening with section headings.

== 0.1.0a1 - 2026-08-18

=== Added

* *Incremental DAG Build Engine:* Dependency tracking with SHA-256 content hashing in `.golem/cache.json`, rebuilding only modified files and their inclusion dependents.
* *AsciiDoc Native Pipeline:* Integration with `asciidoctrine` (Lark AST parser/ASG resolver) and `asciidoctype` (Chameleon ZPT templates) supporting 39 standard node types.
* *Hierarchical Navigation Auto-Discovery:* Automatic sidebar tree generation with numeric prefix stripping (`01-intro.adoc` -> `Intro`), homepage pinning, and explicit `golem.toml` overrides.
* *Multi-Threaded Live Dev Server:* Zero-dependency `ThreadingHTTPServer` with Server-Sent Events (SSE) live browser reload under `/golem-reload` and interactive compiler error overlays.
* *Pluggy Plugin Architecture:* Lifecycle hooks for `on_pre_parse`, `on_ast_created`, `on_asg_created`, `on_post_render`, and `golem_add_subcommands`.
* *CLI Inspection Commands:* `golem plugins` and `golem themes` commands to discover, inspect, and list active and installed extensions.
* *Doctest Integration:* Executable Python code example verification in listing blocks using `asciidoctest`.
* *Fired Clay / Workbench Default Theme:*
** Handcrafted warm paper / workbench aesthetic with automatic `prefers-color-scheme: dark` mode.
** Complete typography system built on Google Fonts Source family (`Source Serif 4` for display/body, `Source Sans 3` for UI chrome, `Source Code Pro` for monospaced code blocks).
** Sub-perceptible SVG `feTurbulence` paper-grain texture data URIs.
** Distinct earth-tone admonition palette (`NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`).
* *Comprehensive Documentation Suite:* Complete user manual, developer guide, and technical specification rewritten as focused, topic-grouped guides.

=== Fixed

* *TOC Scroll Anchors & Description Lists:* Fixed table-of-contents slug anchors and description list node rendering.
* *Navigation Pruning:* Pruned empty non-AsciiDoc directories and defaulted plugin lists cleanly to avoid empty navigation nodes.
