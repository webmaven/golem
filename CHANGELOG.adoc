== [Unreleased]

=== Added

* *Test Coverage Configuration:* Added `pytest-cov` and `coverage[toml]` to dev dependencies with configured coverage targets in `pyproject.toml`.
* *`CONTRIBUTING.adoc`:* Added contributor guide covering development setup, test execution, linting/type-checking, and PR guidelines.
* *Server-Side Syntax Highlighting:* Pygments-powered syntax highlighting integrated into the build pipeline.
* *CI Syntax Canary Test (`tests/test_syntax_invariants.py`):* AST-based test that catches Python 2 `except A, B:` forms across all source files at CI time — a class of bug not detected by ruff's default rule set.

=== Fixed

* *Python 2 Syntax (`except A, B:`):* Corrected five occurrences across `engine.py`, `server.py`, `highlighting.py`, and `cli.py` where the Python 2 multi-exception form was used. In Python 3, `except A, B:` catches only `A` and silently binds the exception to the name `B` — not the intended multi-catch behavior. All corrected to `except (A, B):`.
* *Plugin Activation Gating (`get_plugin_manager()`):* Refactored to a two-pass discovery → registration architecture. `config.plugins` is now the sole authority on enablement and execution order — presence in a discovery source (installed entry point or local `plugins/` directory) alone no longer activates a plugin.
* *Plugin Hook Robustness:* All four build lifecycle hooks (`on_pre_parse`, `on_ast_created`, `on_asg_created`, `on_post_render`) now isolate plugin exceptions — a failing plugin emits a `WARNING` log and processing continues. A `WARNING` is also emitted when multiple plugins modify the same value in a single hook, since the final result is then order-dependent.
* *Hookspec Type Annotations:* Corrected `on_ast_created` hook specification type annotation from `os.PathLike[Any] | Any` to `Any`.
* *Cross-platform file locking:* Implemented cross-platform cache file locking using `filelock` replacing `fcntl`.
* *Configuration Normalization and Precedence Deduplication:* Deduplicated `load_config()` parsing into a centralized `_extract_config_values` normalizer helper, ensuring consistent canonical key precedence (section-scoped > root-level, canonical > alias) across `golem.toml` and `pyproject.toml`.
* *Build-Cycle Navigation Caching:* Cached `discover_navigation()` tree within `build_site()` cycle to prevent redundant recursive filesystem scans per compiled page, passing optional precomputed `nav_tree` to `generate_nav_html`, `get_ordered_nav_pages`, and `get_page_pagination`.
* *CLI Version String:* Updated `--version` option to resolve package version dynamically via `importlib.metadata.version("golem-docs")` with fallback to `dev`, replacing hardcoded string.
* *Project Scaffolding Author:* `golem init` now dynamically discovers the author name from `git config --global user.name` with a fallback to `Your Name`, replacing hardcoded author name.
* *Repository Cleanliness:* Removed internal review artifact `docs_crit_eval.md` and added `*_crit_eval.md` pattern to `.gitignore` to prevent future tracking of review artifacts.
* *Upgraded Dependencies:*
** Bumped `asciidoctrine` requirement to `>=0.2.0a4` and `asciidoctype` to `>=0.1.0a4`.
** Added `pygments>=2.18` as a required dependency.
* *Comprehensive AsciiDoc Docstrings:*
** All internal modules (`config`, `server`, `plugins`, `engine`, `renderer`) now carry full AsciiDoc-formatted docstrings using `asciidocstring` conventions, replacing prior reST/Sphinx markup.
* *CSS Visual Hierarchy (Fired Clay Theme):*
** Fired Clay palette (`FiredClayStyle`) applied to Pygments-highlighted listing blocks.
** New `body_class`, `page_class`, and `content_class` template context variables for per-page layout control.
** Table full-bleed breakout, heading scale, description list (`dl`/`dt`/`dd`) spacing, accent rail, and keyboard focus rings.
** Listing blocks render language badges and callout pills; admonition titles styled as pill labels; inline code within headings uses a muted variant.
* *Dev Server:* Client socket disconnects now logged at `DEBUG` level instead of raising unhandled exceptions.
* *Test Coverage:*
** Modernized test syntax and expanded coverage across `doctest`, `apidoc`, `highlighting`, and `engine` modules.

== [0.1.0a2] - 2026-08-24

=== Added

* *Fine-Grained Cache Invalidation (Issue #1):*
** AST/ASG `node_types` inventory recorded per page in `.golem/cache.json`.
** Theme template fingerprinting and scoped cache invalidation for specific node template changes (e.g. `listing.html` only recompiles pages with code blocks).
** New Pluggy lifecycle hook `golem_mark_stale(changed_files, cache_metadata)` enabling plugins to perform selective cache invalidation.
* *Automated API Documentation Generation (`golem apidoc`):*
** Built-in plugin `golem.plugins.apidoc` using Griffe and `asciidocstring` to introspect packages and generate clean AsciiDoc API reference documentation.

=== Changed

* *Upgraded Dependencies:*
** Upgraded `asciidoctrine` dependency requirement to `>=0.2.0a3` (incorporating parser memoization, underscore emphasis fixes, and listing block bracket fixes).
** Upgraded `asciidoctest` dependency requirement to `>=0.2.0a3` (supporting AST section scoping and named test contexts).

=== Fixed

* *API Reference Formatting:*
** Description list multi-line formatting in apidoc output avoiding parser bloat.
** Truncation of large inline attribute constants (such as HTML templates).
** Heading level offset adjustment for docstrings opening with section headings.

== [0.1.0a1] - 2026-08-18

=== Added

* *Incremental DAG Build Engine:* Dependency tracking with SHA-256 content hashing in `.golem/cache.json`, rebuilding only modified files and their inclusion dependents.
* *AsciiDoc Native Pipeline:* Integration with `asciidoctrine` (Lark AST parser/ASG resolver) and `asciidoctype` (Chameleon ZPT templates) supporting 39 standard node types.
* *Hierarchical Navigation Auto-Discovery:* Automatic sidebar tree generation with numeric prefix stripping (`01-intro.adoc` -> `Intro`), homepage pinning, and explicit `golem.toml` overrides.
* *Multi-Threaded Live Dev Server:* Zero-dependency `ThreadingHTTPServer` with Server-Sent Events (SSE) live browser reload under `/golem-reload` and interactive compiler error overlays.
* *Pluggy Plugin Architecture:* Lifecycle hooks for `on_pre_parse`, `on_ast_created`, `on_asg_created`, `on_post_render`, and `golem_add_subcommands`.
* *CLI Inspection Commands:* `golem plugins` and `golem themes` commands to discover, inspect, and list active and installed extensions.
* *Doctest Integration:* Executable Python code example verification in listing blocks using `asciidoctest`.
* *Fired Clay / Workbench Default Theme:*
** Handcrafted warm paper / workbench aesthetic with automatic `prefers-color-scheme: dark` mode.
** Complete typography system built on Google Fonts Source family (`Source Serif 4` for display/body, `Source Sans 3` for UI chrome, `Source Code Pro` for monospaced code blocks).
** Sub-perceptible SVG `feTurbulence` paper-grain texture data URIs.
** Distinct earth-tone admonition palette (`NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`).
* *Comprehensive Documentation Suite:* Complete user manual, developer guide, and technical specification rewritten as focused, topic-grouped guides.

=== Fixed

* *TOC Scroll Anchors & Description Lists:* Fixed table-of-contents slug anchors and description list node rendering.
* *Navigation Pruning:* Pruned empty non-AsciiDoc directories and defaulted plugin lists cleanly to avoid empty navigation nodes.
