## Decisions (resolved)

1. **Commit granularity:** one commit for the whole Session 2 cluster (matches the
   multi-feature style of `7dc932f`), after the full suite is green.
2. **RECONSTRUCTION.md moves** to `.kilo/plans/RECONSTRUCTION.md` (user-approved), so
   both tracking docs live in the authorized plans directory. Content preserved.
3. **Skip-link class stays `golem-skip-link`** (`skeleton.pt:104`, `golem.css:632`) —
   already implemented, tested, and consistent with the `golem-` prefix convention.
   Note the deviation from issue #27's literal `skip-link` text when closing.
4. **#30 implements only the `t` shortcut.** The other shortcuts in the issue's table
   (`/`, `s`, `?`, `e`) have no target UI in golem; per §5.6 the scope is the theme
   toggle.
5. **Pill colors become `--pill-*` design tokens** (issue #20's hex values as the
   light-mode defaults, dark overrides added) — repo token discipline over raw hex.
6. **Glyph/pill/drawer emission rides section node attributes + the apidoc
   `section.html`**, the same pattern the existing `role` attribute already uses.
   Non-apidoc sections must render unchanged.
7. **B5 ships as a `table.html` override** in `src/golem/templates/default/` (the
   established override pattern: `section.html`, `listing.html`, `heading.html` already
   live there) wrapping the table in `.table-scroll` + CSS `overflow-x: auto;
   min-width: 0`. Do **not** touch column widths (fixed upstream, §2.3).
8. **Housekeeping closings:** #37 (A3′ landed in `8b17e0c`) and #2 (landed in
   `b2279b5`, covered by `tests/test_cli_new.py`) are closed with reference comments.
