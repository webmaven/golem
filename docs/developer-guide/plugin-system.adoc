Golem utilizes `pluggy`—the plugin engine behind `pytest`—to provide clean lifecycle hooks.

== Available Hook Specifications

Plugins implement hooks using the `@hookimpl` decorator from `golem.plugins`:

.my_plugin.py
[source,python]
----
from pathlib import Path
from typing import Any
import click
from golem.plugins import hookimpl

class MyPlugin:
    @hookimpl
    def on_pre_parse(self, raw_content: str) -> str:
        """Called sequentially before Lark parsing. Can mutate raw AsciiDoc source text."""
        return raw_content

    @hookimpl
    def on_ast_created(self, ast: Any) -> Any:
        """Called after Lark parses AsciiDoc source into an AST before semantic resolution."""
        return ast

    @hookimpl
    def on_asg_created(self, asg: dict[str, Any]) -> dict[str, Any]:
        """Called after semantic ASG resolution into a structured dictionary."""
        return asg

    @hookimpl
    def on_post_render(self, html_content: str) -> str:
        """Called after Chameleon layout rendering before writing the HTML page to disk."""
        return html_content

    @hookimpl
    def golem_add_subcommands(self, cli: click.Group) -> None:
        """Attach custom Click subcommands to the main golem CLI during bootstrap."""
        @cli.command("mycmd")
        def my_command():
            click.echo("Custom plugin command executed!")

    @hookimpl
    def golem_mark_stale(
        self,
        changed_files: list[Path],
        cache_metadata: dict[str, dict[str, Any]],
    ) -> list[Path] | None:
        """
        Called during dependency analysis to allow plugins to register stale pages for recompilation.
        Inspects `changed_files` and per-document `cache_metadata` (including `node_types`).
        Returns a list of `Path` objects corresponding to pages that need recompilation.
        """
        return []
----

== Registering Plugins via Entry Points

In your plugin package's `pyproject.toml`:

.pyproject.toml
[source,toml]
----
[project.entry-points."golem.plugins"]
my_plugin = "my_package.plugin:MyPlugin"
----
