This document serves as the living component showcase and specification for Golem's three-layer design token architecture. It exercises token rendering across light and dark themes, verifying typography, surface elevation, visual containment, API autodoc structures, and interactive documentation widgets.

== 1. Symbol Kind Glyph Badges (Dual Coding)

Golem employs a **dual-coding visual system** for language symbols: each symbol kind is distinguished by both a distinct letter glyph (`C`, `M`, `F`, `I`, `T`, `X`, `V`) and an accessible, WCAG AA compliant semantic color pair (foreground and background tint).

== 5. Admonition Callouts

Golem formats all 5 standard AsciiDoc admonition types with custom semantic colors and uppercase labels:

[NOTE]
====
This is a **Note** admonition, utilizing `--color-note` (Forest Teal). It provides supplementary context or background explanations.
====

[TIP]
====
This is a **Tip** admonition, utilizing `--color-tip` (Olive Green). It highlights best practices, keyboard shortcuts, or performance recommendations.
====

[IMPORTANT]
====
This is an **Important** admonition, utilizing `--color-important` (Terracotta Clay). It flags essential prerequisites and crucial requirements.
====

[WARNING]
====
This is a **Warning** admonition, utilizing `--color-warning` (Warm Amber Yellow). It cautions users against unintended consequences or deprecated interfaces.
====

[CAUTION]
====
This is a **Caution** admonition, utilizing `--color-caution` (Crimson Red). It alerts readers to potentially destructive operations or security risks.
====

== 7. Interactive UI & Multi-View Code Listings

=== Multi-View Listing Tabs (Zero-JS)

Code listings support tabbed switching (e.g. Source, ASG, and Preview) through pure CSS `:has()` pseudo-class selectors:

.Example Multi-View Component
[source,python,render="source,preview"]
----
def greet(name: str) -> str:
    """Return a warm greeting."""
    return f"Hello, {name}!"
----

=== Keyboard Shortcuts & UI Buttons

Inline user interface macros render tactile, elevated widgets:

* Open Command Palette: kbd:[Ctrl+Shift+P] or kbd:[Cmd+Shift+P]
* Quick Save: kbd:[Ctrl+S]
* Action Button: btn:[Rebuild Site]
* Menu Sequence: menu:File[Export > Static HTML]
